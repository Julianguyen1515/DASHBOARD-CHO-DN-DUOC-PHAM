Kết nối Google Sheets
Nhập URL để đọc dữ liệu thực
📋 Hướng dẫn
1
Tạo Google Sheet từ template
Mở link template dưới đây, tạo bản sao (File → Make a copy)
2
Publish Sheet ra CSV
File → Share → Publish to web → Chọn tab "Dashboard" → Format: CSV → Publish → Copy link
3
Dán URL vào ô dưới đây
App sẽ tự đọc dữ liệu mỗi khi mở hoặc bấm Làm mới
Google Sheet CSV URL
Đây là link publish CSV từ tab Dashboard trong Google Sheet của bạn.

Cấu trúc Google Sheet
Tab Dashboard cần có các cột sau
Cột A: key (tên biến)
Cột B: value (giá trị)
Cột C: label (nhãn hiển thị)
Cột D: type (loại: number/text/alert)
Cột E: alert_level (danger/warning/success/info/teal)
